Gekoppelde apparaten

Een afgemeld apparaat kan niet meer synchroniseren. Eventuele wijzigingen die daar nog niet gesynchroniseerd zijn, gaan verloren.

Verbinding met GitHub

Gebruik een private repo en een fine-grained token met alleen “Contents: Read and write” op die repo. Het token blijft versleuteld op dit apparaat.

Face ID / passkey

Als je de app zo lang niet gebruikt of hij zo lang op de achtergrond staat. Geldt alleen op dit apparaat.

Wachtwoord wijzigen

De versleutelde back-up kun je alleen openen met je wachtwoord. De leesbare export is niet versleuteld.
